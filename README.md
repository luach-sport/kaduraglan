# כדורגלן (Kaduraglan)

חידון כדורגל בעברית לאנדרואיד ולאייפון. עובד בלי אינטרנט. פותח על ידי Itzko.

- **אתר ההסבר וההורדה:** https://luach-sport.github.io/kaduraglan/
- **הורדה לאנדרואיד (APK):** https://github.com/luach-sport/kaduraglan/releases/latest/download/kaduraglan.apk
- **אייפון (מוסיפים למסך הבית מספארי):** https://luach-sport.github.io/kaduraglan/app/

## מה יש בפנים
- 357 שאלות שנבדקו מול מקורות (כ-30% כדורגל ישראלי), 10 קטגוריות, 6 רמות קושי: מתחיל, אוהד, מתקדם, מומחה, אגדה, בלתי אפשרי.
- סוגי חידות: שאלה אמריקאית, נכון / לא נכון, "מי אני?", סידור לפי השנים, וזיהוי תמונה (נוצר לבד מכל תמונה שמוסיפים).
- 8 מצבים: מסע החידות, אתגר יומי, הישרדות, ראש בראש (2–4 שחקנים על טלפון אחד), אתגר לפי קבוצה, משחק חופשי, זיהוי תמונה, חצי סמל.
- ספריית כדורגל (קבוצות, שחקנים, נבחרות, תחרויות, אצטדיונים), הישגים, דרגות, צלילים ורטט, ערכת צבעים כהה ובהירה.
- עדכוני שאלות בלי להתקין מחדש: אוטומטית מהאתר כשיש אינטרנט, או מקובץ ZIP / JSON. אף עדכון לא מוחק את מה שיש.
- מצב עורך עם קוד גישה (ההתחלתי: `2026`): הוספה ועריכה של שאלות, הוספת תמונות עם כיווץ, שאלות שדווחו, ייצוא חבילה.
- גרסה חדשה של האפליקציה יורדת ומותקנת מתוך האפליקציה כקובץ מלא, ולכן שיתוף ה-APK וגיבוי במנהל הקבצים הם תמיד של הגרסה האחרונה.

## איפה הכל
| מה | איפה |
|---|---|
| האפליקציה (HTML/JS, בלי בנייה) | `www/` |
| השאלות והרשומות (המקור) | `content-src/questions/*.mjs`, `content-src/entities/*.mjs` |
| המאגר שנארז באפליקציה (נוצר) | `www/data/content/*.json` |
| חבילות עדכון שמתפרסמות באתר | `updates/` (מקור החבילות ב-`updates/src/<id>/`) |
| אתר ההסבר | `site/` + `scripts/site/scenes.mjs` (צילומי המסך) |
| בניית ה-APK | `.github/workflows/build.yml`, `scripts/patch-android.sh` |
| בדיקות | `tests/*.test.mjs` |

## הרצה מקומית
```bash
npm install
node scripts/build-content.mjs        # בודק את כל השאלות ובונה את www/data/content
npm test                              # ניקוד, משחקים, עדכונים, גיבוי ושחזור
node scripts/prepare-web.mjs && python3 -m http.server 8765 --directory www   # http://127.0.0.1:8765
```

## בניית APK
כל push ל-`main` בונה APK חתום, מפרסם Release (`v1.01-build<N>`), כותב `update.json` חתום (האפליקציות המותקנות רואות אותו ומציעות "עדכון עכשיו") ובונה מחדש את האתר.
מספר הגרסה: `APP_VERSION` ב-`build.yml`. שם הקובץ בגרסה הוא `1.01.<מספר בנייה>`.
הסיסמה של מפתח החתימה (`signing/release.jks`) נמצאת רק ב-GitHub Secrets בשם `KADURAGLAN_KEY_PASS`. לא מחליפים את המפתח: בלי אותו מפתח אי אפשר להתקין עדכון מעל הגרסה הקיימת.

## הוספה ותיקון של שאלות
- **שאלה חדשה במאגר הבסיס:** מוסיפים לקובץ המתאים ב-`content-src/questions/` עם `id` חדש וייחודי, מריצים `node scripts/build-content.mjs`, ועושים push. נכנס בגרסה הבאה של האפליקציה.
- **תיקון תשובה:** משנים את השאלה ומעלים את `rev` (למשל `rev: 2`). ה-`id` לא משתנה לעולם, כדי שההתקדמות של השחקנים תישמר.
- **נתון שמשתנה** (מספר חולצה, מאמן נוכחי): מסמנים `asOf: '2026-11'`, והאפליקציה מציגה "נכון ל…".
- **בלי להוציא גרסה:** חבילת עדכון (ראו `docs/updates.md`). אחרי push היא יורדת לבד לכל מי שיש לו אינטרנט.
- **מהטלפון:** מצב עורך ← הוספת שאלה / עריכה, ואז "ייצוא השינויים" לקובץ ששולחים הלאה.

## תמונות
באפליקציה אין תמונות של סמלים ושחקנים מראש, בגלל זכויות יוצרים. מוסיפים רק תמונות שמותר להשתמש בהן:
- מהטלפון: מצב עורך ← תמונות חסרות ← בוחרים תמונה. היא מכווצת לבד (WebP, בערך 30–120KB) ונשמרת עם מקור וזכויות.
- בחבילת עדכון: `images.json` + תיקיית `images/` (ראו `docs/updates.md`). `scripts/make-package.mjs` מכווץ אותן.
- כל תמונה יוצרת לבד שאלת זיהוי. מצבי "זיהוי תמונה" ו"חצי סמל" נפתחים כשיש לפחות 4 תמונות מהסוג.

## גיבוי ושחזור
- **ההתקדמות** (נקודות, הישגים, שיאים): פרופיל ← גיבוי ושחזור ההתקדמות. נפרד מהמאגר, ועדכוני שאלות לא נוגעים בו.
- **המאגר**: פרופיל ← ניהול ועדכון מאגר. לפני כל ייבוא נשמר גיבוי אוטומטי (4 אחרונים), ואפשר לשחזר כל אחד מהם או לשמור גיבוי מלא לקובץ.
